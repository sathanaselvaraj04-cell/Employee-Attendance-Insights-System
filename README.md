# Employee-Attendance-Insights-System
A python-based employee attendance analysis project that generates and analyzes attendance data using Pandas and Excel.

## Project Overview

This project uses Python to generate and analyze employee attendance data. The project calculates attendance-related information, working hours, and summary results, and stores the results in Excel files.

## Objective

The objective of this project is to practice working with employee attendance data using Python and learn how to generate data, process it, perform basic analysis, and organize the results in Excel.

## What the Project Does

* Generates employee attendance data
* Processes attendance records using Pandas
* Converts check-in and check-out values into usable time data
* Calculates employee working hours
* Calculates attendance percentages
* Creates employee-wise attendance summaries
* Creates department-wise attendance summaries
* Stores the analysis results in Excel

## Technologies Used

* Python
* Pandas
* NumPy
* Excel
* OpenPyXL

## Project Files

| File                     | Description                                                                   |
| ------------------------ | ----------------------------------------------------------------------------- |
| `generate_data.py`       | Generates the employee attendance dataset                                     |
| `attendance_analysis.py` | Processes the attendance data, performs analysis, and creates summary results |
| `attendance.xlsx`        | Excel file containing the attendance data and analysis results                |
